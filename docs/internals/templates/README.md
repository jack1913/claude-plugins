# Page templates

Copy one when you start a page. The rules behind them are in [the docs standard](../docs-standard.md).

| Template | For |
| --- | --- |
| [plugin-readme.md](plugin-readme.md) | `plugins/<name>/README.md` |
| [how-to.md](how-to.md) | A task page in a plugin's `docs/manual/use/` |
| [commands-reference.md](commands-reference.md) | A plugin's `docs/manual/reference/commands.md` |
| [use-card.md](use-card.md) | A plugin's card in the marketplace `docs/manual/use/` |
| [../../adr/ADR-TEMPLATE.md](../../adr/ADR-TEMPLATE.md) | A decision record |

Changelogs follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); see the standard, §6.
