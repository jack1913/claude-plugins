# Choose a plugin

Find what you want to do; the plugin next to it is the one to install.

| You want to | Plugin |
|---|---|
| Get a logo, colours and a brand book for your business, shop, podcast or app | [brand-creator](../use/brand-creator.md) |
| Turn a logo you already have into favicons, app icons and social images | [brand-creator](../use/brand-creator.md) |
| Find a name, or check one you have | [brand-creator](../use/brand-creator.md) |
| Have Claude write modern SwiftUI, Swift 6 concurrency code and Swift Testing tests | [swift](../use/swift.md) |
| Review a screen you built against Apple's design guidelines | [swift](../use/swift.md) |
| Stress-test a plan before you build it | [batbelt](../use/batbelt.md) |
| Check a number, a legal rule or a market claim against real sources | [batbelt](../use/batbelt.md) |
| Set up a repository so Claude works well in it | [batbelt](../use/batbelt.md) |

Then [install it](install-a-plugin.md). You can install more than one.

## What they won't do behind your back

- **brand-creator** never buys a domain, files a trademark, contacts anyone, or commits to git on its own. It hands you
  those steps.
- **swift**'s review only reports. It never edits your code.
- **batbelt** never touches your files before you approve its plan, and never answers a claim from memory.
