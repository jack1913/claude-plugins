# <picture><source media="(prefers-color-scheme: dark)" srcset="../../assets/brand/swift-dark.svg"><img src="../../assets/brand/swift.svg" alt="swift mark" width="32" height="32"></picture> swift

Have Claude write current SwiftUI, Swift 6 concurrency and Swift Testing, and review screens against Apple's guidelines.

Install it once per Swift project, from inside that project:

```text illustrative
claude plugin marketplace add jack1913/claude-plugins --scope project
claude plugin install swift@jack1913 --scope project
```

- [Build a SwiftUI screen](../../../plugins/swift/docs/manual/use/build-a-swiftui-screen.md)
- [Fix a concurrency error](../../../plugins/swift/docs/manual/use/fix-a-concurrency-error.md), or [write tests](../../../plugins/swift/docs/manual/use/write-tests.md)
- [Review a screen](../../../plugins/swift/docs/manual/use/review-a-screen.md): type `/swift:review`; it only reports.

Everything else is in the [swift manual](../../../plugins/swift/docs/manual/README.md).
