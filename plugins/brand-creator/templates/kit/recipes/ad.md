# Ads

What an ad for this brand keeps, and how we usually make one. `SKILL.md` explains the three weights (Fixed, Default, Example). The brand's values live in the tokens and rules.json; a line you add that pins a value cites a token or a rule, or is tagged `[example]`.

## Fixed

Everything fixed in `SKILL.md` and `golden-rules.md` holds in an ad. So do the copy rules of the masters' README (`brand/assets/masters/README.md`), which the owner approved with the masters. Claims are fixed too: every number, feature, price, client and date an ad states is in `facts.json`.

## Defaults

### How we usually make one

This is the brand's own practice. Follow it, or use a better way of your own: the fixed lines hold either way.

1. Start from an approved master: `brand/assets/masters/README.md` lists each one, its size and the copy rules. Take the size the channel asks for; a size no master has is yours to make in the same language.

2. Keep the master's canvas and layout. Change only the copy, and a picture where the copy rules allow it.

3. Take every claim (a number, a feature, a price, a client, a date) from `facts.json`, and keep the copy rules of the masters' README.

4. Nothing reaches outside the canvas, and no text is covered by anything or runs into other text. In the brand project, `brand-creator masters check` proves it for a masters round.

5. Anything new (a direction, a layout, a size, a line of copy) is yours to make in the same language, in line with the fixed parts: say what you decided.
