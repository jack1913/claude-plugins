# Ads

Steps only. The brand's values live in the tokens and rules.json; a line you add that pins a value cites a token or a rule, or is tagged `[example]`.

1. Start from an approved master: `brand/assets/masters/README.md` lists each one, its size and the copy rules. Take the size the channel asks for; a size no master has is a proposal for the owner.

2. Keep the master's canvas and layout. Change only the copy, and a picture where the copy rules allow it.

3. Take every claim (a number, a feature, a price, a client, a date) from `facts.json`, and keep the copy rules of the masters' README.

4. Nothing reaches outside the canvas, and no text is covered by anything or runs into other text. In the brand project, `brand-creator masters check` proves it for a masters round.

5. Anything new (a direction, a layout, a size, a line of copy) is a proposal: label it and ask the owner.
