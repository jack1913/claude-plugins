# Source of the marks in this folder

One per direction folder: `rounds/r[[fill: N]]/[[fill: direction]]/SOURCE.md`. It says where each mark came from, so a later session can tell what was drawn, what was traced and what was fixed by hand. Fill every marker; write "none" where a field does not apply.

- Direction: [[fill: the direction's word name]]
- Date: [[fill: YYYY-MM-DD]]
- Engine: [[fill: use-llm design canvas | Claude Code /design | Claude-drawn SVG (the owner's yes is in BRAND-STATE.md, dated YYYY-MM-DD)]]
- Where the drawing is: [[fill: the canvas folder and artboard file, for example .design/<slug>/<artboard>.dc.html, or the link of the artboard's claude.ai artifact]]
- Prompts: [[fill: the prompts, word for word, one line per item and option; none when nothing was generated]]
- Image model: [[fill: the model name; none when no image was generated]]
- Images and cost: [[fill: how many images were generated, the cost per image and the total in dollars; 0 when none]]
- Trace settings: [[fill: the exact command, the threshold and turdsize, and the trim and pad steps before it; none: redrawn, or none: pixel marks written as rects]]
- Fixed by hand: [[fill: what was fixed by hand in the traced or redrawn SVG: curves, specks, the fill colour, anything else]]
- Lineage: [[fill: for each kept item, the option ID it came from and every step after it, for example family1-bc-3, redrawn as family2-roller-1, the judge's fixes by hand, brand-creator.svg]]
- Agents: [[fill: per run, the agents, their models and the tokens used; none when no agent drew]]
