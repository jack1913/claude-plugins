# P2 Naming (pointer: the brand-naming skill is the single source)

- **When:** only when the name is open or at risk, and before any drawing (G1 comes before G2).
- **How:** read and follow [the brand-naming skill](../../../brand-naming/SKILL.md) fully; this file holds no method of its own.
- **Inputs:** BRIEF.md (name language, region and profile from G0), the strategy core draft, `research/cliches.md`, the five-competitor lineup.
- **Outputs:** `research/names/<date>-check.md` (from `brand-creator names`) and `research/names/<date>-verdict.md` (go / go-with-conditions / no, "screening, not clearance"), with a Launch TODO seed.
- **Gate G1:** the owner picks; buying domains and filing trademarks stay the owner's actions (G7). Never call a name "available" or "clear".
