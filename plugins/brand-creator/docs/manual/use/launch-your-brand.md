# Launch your brand

Get a launch checklist and do it one step at a time. You do each step: Claude never buys, files, registers or contacts
anyone for you.

## Before you start

- You have a brand project. Run a name check first if the name is open, or the domain and handle rows will say UNKNOWN.
  See [Name your brand](name-your-brand.md).

## Do it

1. Type:

   > /brand-creator:launch

   Use `--name <candidate>` when naming screened several names and you want the checklist for one.

2. Claude writes `LAUNCH.md` from your local files: trademark first, then domains and handles (with the date each was
   checked), e-mail, deploy, renames and the print hand-off.
3. Claude hands you one step: the first unticked box. You get the reason in one sentence, the exact click path (the page to
   open, what to type, which button), the cost when it's known, and what to tell Claude afterwards.
4. Do the step yourself. Tell Claude what you did. Claude records it, you tick the box, and the next step comes.

Ask "buy it for me" or "file it", and Claude answers with the hand-off, not the act.

## Rechecking

Each name state is one source's reading on one day: REGISTERED, NOT-FOUND or UNKNOWN. Never read one as "available".
If a check is a few days old before you buy or file, Claude says "recheck first" and offers to run it again.

## Check it worked

`LAUNCH.md` exists in your project, and the boxes you did are ticked. Ticks survive a regeneration.

## If something goes wrong

| You see | Do this |
| --- | --- |
| Domain rows say UNKNOWN | Run the name check first, and agree to online lookups |
| No project found | Open Claude Code in the project folder |
