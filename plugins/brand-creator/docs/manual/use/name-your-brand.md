# Name your brand

Get name ideas, or find out whether a name you have is taken. You get a short verdict memo for each name. It is
screening, not clearance.

## Before you start

- brand-creator is installed. You don't need a brand project: Claude makes a small folder for the memo if you have none.

## Find or check a name

1. Ask in your own words, such as "name ideas for my bakery" or "is the name Loaf taken?", or type the command:

   > /brand-creator:brand-naming

2. Answer a few quick questions: the language of the name, the kind of brand (software, consumer or personal) and the
   region. Each has a suggested answer.
3. For name ideas, Claude builds candidates in several styles, cuts the weak ones with a reason so you can rescue one, and
   checks meaning and sound in each language your audience speaks.
4. Before any name leaves your machine, Claude tells you which services it would ask and waits for your yes.
5. Claude screens the shortlist and writes a memo with a go, go-with-conditions or no verdict for each name.
6. You pick. You buy the domain and file the trademark yourself; the memo links the searches you run.

## What the answers mean

A name check reports what one source said on one day: REGISTERED, NOT-FOUND or UNKNOWN. It never says "available" or
"clear". Domains and, for software brands only, package registries are checked. Trademark offices are never queried.

## Check it worked

The project has a names memo with a verdict per shortlisted name and the date each source was read.

## If something goes wrong

| You see | Do this |
| --- | --- |
| Every source says UNKNOWN | Names stay on your machine until you agree to online lookups. Say yes when Claude asks |
| "cannot run" | Run `/brand-creator:setup` |
