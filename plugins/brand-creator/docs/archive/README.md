# Archive

Frozen, point-in-time records; never edited. They explain how brand-creator was built. They do not describe how it works
today: for that, read the [manual](../manual/README.md) and the [internals](../internals/README.md).

| Record | What it holds |
| --- | --- |
| [build-log.md](build-log.md) | How 0.1.0 was built, stage by stage |
| [decisions-log.md](decisions-log.md) | The numbered decisions made while building it, from the first stage to the move into the monorepo |

New decisions are [ADRs](../adr/README.md), not entries in the decisions log.
