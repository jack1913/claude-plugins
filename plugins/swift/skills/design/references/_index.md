# Design references

Every file in this folder, and what to open it for. `SKILL.md` has the same pointers as a topic router.

| File | Use it for |
| --- | --- |
| `color.md` | Which colours text, backgrounds, accents and status indicators use; dark mode and higher contrast |
| `hierarchy-layout.md` | How a screen ranks, groups, spaces and aligns its content |
| `liquid-glass-design.md` | When a design uses Liquid Glass, which variant, where colour goes, how shapes nest |
| `motion.md` | When to animate, which spring, how long, and what Reduce Motion changes |
| `platform-idioms.md` | How one app takes the shape of each platform: navigation, toolbars, inspectors, input, control sizes |
| `sf-symbols.md` | Choosing a symbol, its variant and rendering mode, sizing and animating it |
| `tokens.md` | Working with a project's design tokens, and the starter set to suggest when it has none |
| `typography.md` | Text style per role, Dynamic Type, weight, monospaced digits, line limits |
