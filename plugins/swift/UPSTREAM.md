## Findings

Names upstream uses that Apple's documentation index did not have on 2026-09-25. While a row is open, `check-apis.py` ignores its name for this reason. Status says what was decided: **Fixed** (the text now uses the real API, see Deviations; the ignore entry is gone), **Resolved** (Apple documents it as of the date given; the ignore entry is gone) or **Open** (with the reason it stays).

| Name | Upstream file | Nearest Apple API | Status |
|---|---|---|---|
| `AXDateDataAxisDescriptor` | `references/charts-accessibility.md` | `AXNumericDataAxisDescriptor`, `AXCategoricalDataAxisDescriptor` | **Fixed** 2026-09-25: no such type in Apple's doc JSON (404) or Accessibility index, nor in the 27.0 SDKs; the snippet uses a numeric axis over seconds (see Deviations) |
| `VerticalTabViewStyle` | `references/latest-apis.md` | `VerticalPageTabViewStyle` (Apple's `CarouselTabViewStyle` metadata says renamed: `VerticalTabViewStyle`, but its deprecation text says `VerticalPageTabViewStyle`) | **Fixed** 2026-09-25: no page in Apple's doc JSON (404) and no declaration in the 27.0 SDKs, only the `renamed:` string; the text now names `VerticalPageTabViewStyle` (see Deviations). The name stays in the text on purpose, as the wrong one, under that ignore group |
| `navigationTransitionSource` | `references/latest-apis.md` | `matchedTransitionSource(id:in:)`, `navigationTransition(_:)` | **Fixed** 2026-09-25: no page in Apple's doc JSON (404) and no declaration in the 27.0 SDKs; the snippet uses `matchedTransitionSource(id:in:)` and `navigationTransition(.zoom(sourceID:in:))` (see Deviations) |
| `navigationTransitionDestination` | `references/latest-apis.md` | `matchedTransitionSource(id:in:)`, `navigationTransition(_:)` | **Fixed** 2026-09-25: no page in Apple's doc JSON (404) and no declaration in the 27.0 SDKs; the snippet uses `matchedTransitionSource(id:in:)` and `navigationTransition(.zoom(sourceID:in:))` (see Deviations) |
